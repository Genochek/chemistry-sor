В первую очередь выучи
Как считать группы у азота, почему у аминокислот нумерация начинается с COOH и откуда берётся связь –C(=O)–NH–. Из реакций повтори соль амина, бромирование анилина и амфотерность аминокислот.

Название и формула

Из названия в формулу

Соберём 2-амино-3-метилбутановую кислоту (валин).

  1. «Бутановая» даёт четыре C в основной цепи. Углерод в COOH уже входит в эту четвёрку и получает номер 1.
  2. Поставь NH₂ у C₂, метил CH₃ у C₃.
  3. Заполни свободные связи числами H. У нейтральных атомов в этих примерах C образует 4 связи, N — 3, O — 2, H — 1. Двойная связь считается за две.
HOOC–CH(NH₂)–CH(CH₃)–CH₃

У C₂ три связи с соседями по схеме, поэтому ему нужен один H. Скобки показывают ветку у предыдущего атома.

Из формулы в название

CH₃–CH(NH₂)–CH₂–COOH

Нашёл COOH? Это кислота. Возьми самую длинную цепь с её углеродом и считай от него. Здесь четыре C, а NH₂ на третьем. Получается 3-аминобутановая кислота.

У простого амина без COOH смотри на группы у N. В CH₃–NH–CH₂–CH₃ к N пришиты метил и этил. Это вторичный амин, метилэтиламин.

Молекулярная формула показывает количество атомов. Например, C₃H₉N подходит сразу нескольким аминам.

Амины и изомеры

Считай углеродные группы у N

Амины — производные аммиака NH₃, где один, два или три H заменены углеводородными группами. Неподелённая пара электронов N позволяет ему принять H⁺, поэтому амины проявляют основные свойства.

  • Одна группа — первичный R–NH₂, например метиламин CH₃–NH₂.
  • Две — вторичный R–NH–R′, например диметиламин (CH₃)₂NH.
  • Три — третичный R₃N, например триметиламин (CH₃)₃N.

Предельные амины содержат насыщенные углеводородные группы, например этил. У непредельных есть кратная связь в такой группе, например C=C. У ароматических N связан прямо с ароматическим кольцом. Анилин C₆H₅–NH₂ — первичный ароматический амин.

Что меняется у изомеров

Изомерия — явление, при котором одной молекулярной формуле соответствуют разные структуры или разные расположения атомов в пространстве. Такие вещества называют изомерами.

  • Скелет. Прямая или разветвлённая цепь: CH₃–CH₂–CH₂–CH₂–NH₂ и (CH₃)₂CH–CH₂–NH₂.
  • Положение группы. У CH₃–CH₂–CH₂–NH₂ и CH₃–CH(NH₂)–CH₃ группа NH₂ стоит у разных C.
  • Группы у азота. Для C₃H₉N к двум предыдущим формулам добавь CH₃–NH–CH₂–CH₃ и (CH₃)₃N. Всего четыре структурных изомера-амина.

Аминокислоты

Узнай по двум группам

В аминокислоте есть аминогруппа и карбоксильная группа. У обычной α-аминокислоты NH₂ стоит у углерода рядом с COOH (C₂). У β-аминокислоты она у C₃, у γ — у C₄.

H₂N–CH(R)–COOH

Подставь вместо R водород и получишь глицин H₂N–CH₂–COOH. Подставь CH₃ и получишь аланин H₂N–CH(CH₃)–COOH.

У аланина C₂ связан с четырьмя разными группами. Он асимметрический, поэтому у аланина есть две несовмещаемые зеркальные формы. Это оптическая изомерия. У глицина у C₂ два одинаковых H.

Какие бывают и зачем нужны

По строению бывают алифатические, например глицин, и ароматические, например фенилаланин. В школьных примерах лишняя COOH даёт кислый характер (аспарагиновая кислота), дополнительная основная группа — основной (лизин). Пример нейтральной — глицин.

Амфотерность — способность реагировать и с кислотой, и со щёлочью. NH₂ принимает H⁺, COOH отдаёт H⁺. Около нейтрального pH глицин в основном находится в виде цвиттер-иона ⁺H₃N–CH₂–COO⁻. Заряды двух групп в сумме дают ноль.

Организм собирает белки из α-аминокислот. Заменимые он может синтезировать, незаменимые должны поступать с пищей. Валин — пример незаменимой.

Реакции, которые стоит повторить

Амины

В воде метиламин принимает H⁺. Появляется OH⁻, и среда становится щелочной.

CH₃NH₂ + H₂O ⇌ CH₃NH₃⁺ + OH⁻

С кислотой получается соль. Щёлочь возвращает из соли свободный амин.

CH₃NH₂ + HCl → [CH₃NH₃]Cl [CH₃NH₃]Cl + NaOH → CH₃NH₂ + NaCl + H₂O

Получение. Из хлорметана и избытка аммиака. Суммарное уравнение:

CH₃Cl + 2NH₃ → CH₃NH₂ + NH₄Cl

Анилин

У анилина электронная пара азота частично делокализована по кольцу, поэтому он слабее как основание, чем аммиак и метиламин.

C₆H₅NH₂ + HCl → [C₆H₅NH₃]Cl

Бромная вода. Обесцвечивается, выпадает белый осадок 2,4,6-триброманилина. Первый номер получает атом кольца, связанный с NH₂.

C₆H₅NH₂ + 3Br₂ → C₆H₂Br₃NH₂↓ + 3HBr

Получение. Восстановление нитробензола. Группа NO₂ превращается в NH₂.

C₆H₅NO₂ + 6[H] → C₆H₅NH₂ + 2H₂O

Глицин с кислотой и щёлочью

С кислотой NH₂ превращается в NH₃⁺. Со щёлочью COOH превращается в карбоксилат.

H₂NCH₂COOH + HCl → [H₃N⁺CH₂COOH]Cl⁻ H₂NCH₂COOH + NaOH → H₂NCH₂COONa + H₂O

С NaHCO₃ карбоксильная группа образует соль. Выделяется CO₂.

H₂NCH₂COOH + NaHCO₃ → H₂NCH₂COONa + CO₂↑ + H₂O

Эфир и получение глицина

Со спиртом карбоксильная группа даёт сложный эфир. Ниже сокращённая школьная запись с катализом кислотой.

H₂NCH₂COOH + CH₃OH ⇌ H₂NCH₂COOCH₃ + H₂O

Из хлоруксусной кислоты и избытка аммиака получают глицин.

ClCH₂COOH + 2NH₃ → H₂NCH₂COOH + NH₄Cl
Ещё два типа задач из учебника

Горение. Если по условию азот выделяется как N₂, баланс для этиламина такой:

4C₂H₅NH₂ + 15O₂ → 8CO₂ + 14H₂O + 2N₂

Выход продукта. Из 250 г нитробензола теоретически получится 250 ÷ 123 × 93 ≈ 189 г анилина. Если получили 150 г, выход равен 150 ÷ 189 × 100% ≈ 79,4%. Сначала найди теоретическую массу по уравнению.

Пептидная связь и белки

Пептидная связь соединяет карбонильный C одного остатка с N следующего. На схеме забери OH у COOH первой аминокислоты и H у NH₂ второй. Из них получается вода, между остатками остаётся –C(=O)–NH–.

H₂N–CH₂–COOH + H₂N–CH(CH₃)–COOH → H₂N–CH₂–C(=O)–NH–CH(CH₃)–COOH + H₂O

Читай цепь от свободной аминогруппы (N-конец) к свободной карбоксильной (C-конец). Здесь сначала глицин, затем аланин, поэтому это глицилаланин (Gly–Ala). Если поменять порядок, получится аланилглицин.

В линейном пептиде из n остатков n − 1 пептидных связей. Трипептид даёт две связи и две молекулы воды при образовании из аминокислот. При гидролизе вода расходуется и связи разрываются. Полный гидролиз белка даёт аминокислоты.

Белки состоят из одной или нескольких полипептидных цепей. Они содержат C, H, O, N, часто S.

Проверь себя

Сначала запиши решение, потом открой строку с ответом.

1. Собери формулу 3-аминопропановой кислоты.

H₂N–CH₂–CH₂–COOH. Углерод COOH — первый, NH₂ стоит на третьем, то есть β-углероде.

2. Назови CH₃–CH(NH₂)–COOH.

2-аминопропановая кислота, или аланин. В цепи три C, NH₂ стоит на C₂.

3. К какому типу относится CH₃–NH–CH₂–CH₃?

К вторичным аминам. У N две углеродные группы. Число атомов C во всей молекуле на этот тип не влияет.

4. Что увидишь, если к анилину добавить бромную воду?

Раствор теряет окраску, появляется белый осадок 2,4,6-триброманилина.

5. Допиши реакцию аланина с NaOH.

H₂N–CH(CH₃)–COOH + NaOH → H₂N–CH(CH₃)–COONa + H₂O. В этой реакции меняется карбоксильная группа.

6. Сколько трипептидов выйдет из трёх разных аминокислот, если каждую брать один раз?

Шесть. На первое место можно поставить любую из трёх, на второе остаются две, на третье — одна. У каждого трипептида две пептидные связи.
